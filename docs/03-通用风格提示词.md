# 03 · 通用风格提示词（任意主题可用）

> 用途：**它是"风格层"，不是"内容层"。** 把它接在任何视频任务后面（或前面），产出的片子就会带上同一套审美。
> 它规定"怎么看起来像"，不规定"讲什么"。换成卖咖啡、讲财报、解释量子力学，风格不变。
> 长度：可直接整段贴入。

---

# 【风格规范】Claude Motion — 暖黑·单点·无剪接

## 一句话气质
**暖近黑底上一张纸白，一个赤陶橙的点替所有东西当演员；不剪断，只变形；敢停，敢白，敢只有一个字。**

## 一、视觉令牌（不许改）

```
底色      #141413   （暖近黑。禁止 #000000，纯黑是"屏幕熄灭"，暖黑是"暗房里的纸"）
纸白      #F0EEE6   （文字与亮场底色）
面板      #1F1F1D / #2A2926
灰阶      #B0AEA5（次）/ #686760（弱）
强调      #D97757   ← 全片唯一的彩色，单帧覆盖 ≤ 3%
高光      #FFA880   （描边、发光核心）
语义      #7AC478 通过 / #EC5450 失败 / #6A9BCC 链接 / #E8B25A 提醒
亮场      #F0EEE6 底 / #FCFBF7 卡片 / #DEDBD0 描边
```

## 二、字体角色（四种，不许混用）

| 角色 | 字体 | 用途 | 字距 |
|---|---|---|---|
| 中文标题 | Noto Sans CJK SC **Black** | 最重要那几句 | 0 |
| 正文 | 同族 Bold/Medium/Regular | 次级 | 0 |
| **机器语汇** | Noto Sans **Mono** CJK SC | HUD、代码、序号、时间码 | **+0.22em** |
| 拉丁数字/短词 | **Poppins** Bold/Medium | "30%"、"2026" | 略正 |
| 品牌名 | **Lora Italic** 600 | 只给名字里那一个拉丁词 | 0 |

**中英混排 = 同字号、同基线、换字体。** 不缩英文、不换行、不斜体。中文标点用**空心「。」**，与强调橙同形——**加一个标点就有重音。**

## 三、排版法则

1. **字号跨度 ≥ 30 倍**（巨型 560px ↔ 注释 18px）。层级靠数量级，不靠"粗一点"。
2. **留白 ≥ 88%**。画面墨迹占比不超过 12%。宁可空，不要满。
3. **安全边距左右 76px**。四角常驻 HUD：左上品牌（橙点+宽字距）、右上时间码、左下帧计数、右下"示意"标注、底边细进度条。
4. **双栏分工**：一侧演"演示"（卡片/面板/代码），一侧写"结论"（章节号 + 巨型标题 + 三条清单）。
5. **章节号格式**：`01 / 修 BUG`、`02 / 做文档`——等宽字体、橙色、宽字距。
6. **HUD 必须吃同一套后处理**（跟着抖、跟着色散），不能像贴上去的水印。
7. **全部数据、代码、表格都要标注"示意画面 / 示意数据 / 来源"在画面里**，不只在文档里。

## 四、色彩节奏

- **全片至少 1 次明暗反转**，用 **iris（圆形遮罩）**，圆心必须落在画面里"有意义的那一点"上（不是画面中心）。
  `R = 36 + 2400·inout_cubic，12px 橙边环 + 沿圆周 64 点光环，0.5 秒`
- 亮场不是反色，是**换纸**：底色 #F0EEE6、卡片 #FCFBF7、墨色 #141413、通过用深绿 #409654。
- **橙色只做"事件"**：光标、句号、序号、进度条、关键数字。不做背景、不做大面积填充。

## 五、运动语法

### 铁律
**0 次硬切。** 任何两段之间的过渡由"同一个元素的运动/变形"承担。**你能听见剪辑点，但不应该看见切。**

### 允许的转场只有这六类
1. **形态 morph**：圆点 ↔ 光标条 ↔ 面板 ↔ 圆，用同一个半径变量插值
2. **iris 圆形遮罩**：见上
3. **粒子重组**：元素按**最小位移**飞向新形状，每颗延迟 0–0.18s，路径带抛物线弧度
4. **冲击爆发**：环 30→1500px + 白闪 + 色散 + 抖动，四件事**同时**发生
5. **横向光扫**：12–16 条亮线 3500–6000px/s 掠过
6. **排版 slam**：字放大 1.25–2.3 倍 + 纵向模糊 70px，0.24 秒收回到 1 倍

### 缓动纪律
- 主力 `out_expo`（快出慢停，干脆、自信）+ `smooth`；次选 `out_cubic` / `inout_cubic`
- `out_back` 少量（进场过冲）；`spring` 极少量
- **禁止 `out_elastic`——不做弹跳。一个自信的品牌不晃。**
- 同组元素错峰 **0.08–0.18s**，不要同时出现

### 必做手笔
1. **主角元素永远有一个**：全片有一颗点/一条线/一个方框在"扮演角色"，任何一帧都在。
2. **幽灵拖尾**：主角移动时画 8–26 个历史位置，alpha ∝ k²。
3. **橙色句读**：句号、逗号、破折号单独上橙色。

## 六、节奏法则

1. **BPM 必须是 120（或 60/90 的整数倍）**：1 拍 0.5s、1 小节 2s。**所有段落边界落在小节线上。**
2. **结构长度序列**：4 / 4 / 4 / 6 / 4 / 8 秒——"起承转爆收留"。
3. **至少 3 处真静音**，深度至少 −37dB，最长一处 ≥ 0.4s。**静音和留白是预算，不是浪费。**
4. **阅读速度 2.6–4.6 字/秒**（舒适阈 8–10，故意压一半）。落款 1.0–1.6 字/秒。**无一句超过 6 字/秒。**
5. **开头 0–2 秒必须是信息真空**：画面几乎空，只有母题元素。然后一次性爆发。
6. **结尾必须回扣开场**：同一句话、同一个元素。

## 七、声音法则

- **全合成，零采样**：正弦/FM/噪声 + 包络，用代码写 kick / snare / hat / bass / pluck / bell / pad / impact / sweep / click。
- **小调，i–VI–III–VII**；旋律取五声音阶；**唯一的明亮色彩只留给"成功/答复"那一下**。
- **目标 −15 LUFS，真峰值 ≤ −1 dBTP**（两个都要达，只达一个不算）。
- **音效必须与画面动作逐点对位**，偏差 ≤ ±60ms。最好的办法是让画面和音频读同一张时间表。

## 八、文案语气

1. **短句，句号结尾**。单句 ≤ 18 字。不写"我们致力于……"。
2. **第一人称，像人说话**。开场用一个请求句（"帮我弄一下。"），结尾用同一个请求句回扣。
3. **幽默靠降格**：复杂的东西画简单（把 bug 画成一只呆萌小虫），不靠亢奋。
4. **自指代替自夸**："你正在看的每一帧，都是我写的代码"——把"我很强"翻译成"你可以自己验证"。
5. **数字要有来源，没来源就不出现**。
6. **敢于只有两个字**（"好。"）。

## 九、禁止清单（Do NOT）

```
✗ 用 #000000 纯黑
✗ 第二个强调色
✗ 同时出现三个以上视觉元素
✗ 任何硬切/淡入淡出黑场
✗ 文字逐字弹出的"打字机"以外的廉价动效
✗ 弹性回弹（elastic / 果冻感）
✗ 满屏堆特效、粒子滥用、光斑乱飞
✗ 长段文字（超过 2 行就是长段）
✗ 连续翻页式排版（PPT 感）
✗ 无来源的跑分/价格/竞品对比
✗ 一直响不停（没有静音段）
✗ 空喊"最强/领先/颠覆"
✗ 背景音乐盖过人声或画面节奏
✗ 用贴图/生成图像冒充设计（本风格纯代码绘制）
```

## 十、12 行最小执行清单

```
1  母题：一个原语，贯穿全片，最后一帧还在
2  底色 #141413，文字 #F0EEE6，只有 #D97757 一个彩色
3  字号跨度 ≥ 30 倍，留白 ≥ 88%
4  四角 HUD + 底边进度条，且吃同一套后处理
5  0 次硬切；只用六类运动转场
6  out_expo 为主；不做弹跳；错峰 0.08–0.18s
7  120 BPM，段落边界在小节线上
8  至少 1 次 iris 明暗反转，圆心落在"有意义的点"
9  至少 3 处真静音，最长 ≥ 0.4s
10 阅读 2.6–4.6 字/秒，无一句超过 6 字/秒
11 −15 LUFS 且 TP ≤ −1 dBTP；音画 ±60ms 对位
12 首尾闭环；静音观看能懂；数据都标"示意"
```

## English mirror（给不吃中文的模型用）

> **Style: Claude Motion — warm-black, single-dot, cutless.**
> Warm near-black #141413 (never #000000), paper cream #F0EEE6, one terracotta accent #D97757 (≤3% of any frame), highlight #FFA880. Four type roles: CJK Black for headlines, CJK Mono with +0.22em tracking for machine HUD, Poppins for Latin numerals, Lora Italic for the brand word only. Type scale spans ≥30×; ≥88% empty space; 76px side margins; persistent four-corner HUD (brand / timecode / frame counter / "illustrative" note) plus a bottom progress bar, all sharing the same post-processing. **Zero hard cuts** — transitions are morph, iris (R=36+2400·inout_cubic, 12px orange rim + 64-point halo), particle reflow by minimum-displacement assignment, impact bursts, horizontal light sweeps, and typographic slams. Ease with out_expo and smooth; never elastic. 120 BPM; section boundaries on bar lines; structure 4/4/4/6/4/8 s. At least three real silences (longest ≥0.4s) and one full light/dark inversion via iris. Reading speed 2.6–4.6 chars/sec, never above 6. Fully synthesized score, minor key i–VI–III–VII, −15 LUFS and true peak ≤ −1 dBTP, every sound effect within ±60ms of its visual. Copy: first person, short sentences ending in periods, one request line that opens and closes the film. Never fake numbers; label all data incidental.
